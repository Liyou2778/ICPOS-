# ICOPS MVP · 五幕演示脚本（评审现场操作指引）

> 目标：十五分钟内完整呈现「矿山施工全流程智能运营」闭环，全程离线演示模式可跑。
> 口径统一：所有数字均由数据库/知识库直读（防幻觉第一道防线）；生成内容均标注“AI 生成初稿，需人工确认”。
> 环境：`tools\start-icops.bat` 一键启动后浏览器打开 http://127.0.0.1:8000/，登录 admin / icops2026。

---

## 第一幕 · 需求输入与驾驶舱总览（约 2 分钟）

- **页面**：登录页 → 运营驾驶舱（`/dashboard`）
- **操作与话术**：
  1. 登录进入「运营驾驶舱」；
  2. 指向指标卡：在役 7 台设备（作业/故障分布）、今日产量 6.7 万吨、开放预警 4 条、项目进度 62%；
  3. 指向右侧「AI 调度 vs 人工基线」柱图：人工空载率 27.0% → AI 6.4%（A/B 对比）；
  4. 指向下方 30 天趋势：日运量上升、末期故障告警抬升（对应后幕预警剧情埋点）。
- **演示要点**：强调“一个平台看到矿山全局——设备/产量/效率/预警”。

## 第二幕 · 方案生成：需求一句话，方案三套起（约 3 分钟）

- **页面**：方案工作台（`/workspace`）
- **操作与话术**：
  1. 点击预置「矿山施工」示例或直接输入：“年产 200 万吨矿石、工期 3 年、预算 1.5 亿元，帮我生成施工方案并推荐设备”；
  2. 演示智能体**主动追问**：先输入“我想买一台挖掘机”→ 系统不编造，反问场景/产量/预算/工期；
  3. 补齐需求后生成：展示 **3 套选型方案**（型号/数量/参数），三年 TCO 明细（购置/能耗/维保/残值四类），对比图；
  4. 切「投标方案」演示：≥6 章节 + **招标响应度检查全部“已响应”**；
  5. 点击「导出 Word」下载文档（评审前可预导出 PDF）。
- **演示要点**：单份方案从 3–7 天 → 30 秒内（界面显示实测耗时）；数值可溯源。

## 第三幕 · 施工调度与设备地图（约 3 分钟）

- **页面**：设备地图监控（`/map`）→ 智能对话中调度命令
- **操作与话术**：
  1. 地图展示设备实时位置（绿=作业/红=故障/黄=待命），WebSocket 每 5 秒推送；
  2. 点击矿卡 T01 → **轨迹回放**（最近 120 点，含速度/载荷）；
  3. 回到对话输入：“空载率太高，帮我调度派车”→ 返回派单表（4 条）与空载率；
  4. 制造故障场景：“矿卡 T02 故障了，立即重调度”→ **动态重调度**排除 T02 重新求解，并强调“调度结论为建议执行，须调度员确认”（回复“确认调度方案”下发）。
- **演示要点**：电子围栏示意 + 车铲匹配 + **人机协同安全边界**。

## 第四幕 · 预测性维护与故障闭环（约 3 分钟）

- **页面**：智能运维中心（`/maintenance`）
- **操作与话术**：
  1. 「预警」页：展示开放预警，每条含**五要素**（异常部件/可能原因/严重等级/建议措施/剩余可用时间）；
  2. 「预测」页：输入 T04 → 命中风险（HYD-01，置信度 99%，RUL 0h），说明该设备已由模型提前识别温漂前兆；
  3. 「诊断」页：输入自然语言“液压油温高、漏油”→ Top3 诊断及递减置信度（78%/74%/70%）+ 维修方案；
  4. 输入知识库外问题验证**拒答**（不编造、转人工）；
  5. 预警行点「一键生成工单」→ 生成 WO 工单（六要素）并出现在工单页。
- **演示要点**：非突发故障**提前 34h 预警**（模型报告数据），工单自动生成、备件缺货自动提示。

## 第五幕 · 智能对话：自然语言运营中枢（约 3 分钟）

- **页面**：智能对话（`/chat`）
- **操作与话术**：
  1. 用一句自然语言提问“帮我生成矿山施工方案…”→ 看 **SSE 流式逐字输出**与右上“方案生成智能体”路由标识、引用来源折叠；
  2. 多轮追问：“把上面方案里第二套的三年 TCO 报给我”→ 系统记忆上下文并回答（58,310,040 元）；
  3. 换话题：“T04 会不会出问题？”→ 路由至设备运维智能体返回预测；
  4. 问工艺知识：“露天矿爆破单耗一般多少？”→ RAG 检索带**句级摘要与引用来源**（0.35~0.55 kg/m³）；
  5. 演示结束页：转人工入口。
- **演示要点**：一个入口触达五个智能体（路由标签可见），多轮可续、答案可溯源。
