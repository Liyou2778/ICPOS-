# ICOPS MVP · 五幕演示脚本（评审现场操作指引）

> 目标：十五分钟内完整呈现「矿山施工全流程智能运营」闭环，全程离线演示模式可跑。
> 口径统一：所有数字均由数据库/知识库直读（防幻觉第一道防线）；生成内容均标注“AI 生成初稿，需人工确认”。
> 环境：`tools\start-icops.bat` 一键启动后浏览器打开 http://127.0.0.1:8000/，登录 admin / icops2026。

---

## 第一幕 · 需求输入与驾驶舱总览（约 2 分钟）

- **页面**：登录页 → 运营驾驶舱（`/dashboard`）
- **操作与话术**：
  1. 登录进入「运营驾驶舱」；
  2. 指向指标卡：在役 7 台设备（作业/故障分布）、今日产量 6.7 万吨、开放预警 4 条、项目进度 62%；
  3. 指向右侧「AI 调度 vs 人工基线」柱图：人工空载率 27.0% → AI 6.4%（A/B 对比）；
  4. 指向下方 30 天趋势：日运量上升、末期故障告警抬升（对应后幕预警剧情埋点）。
- **演示要点**：强调“一个平台看到矿山全局——设备/产量/效率/预警”。

## 第二幕 · 方案生成：需求一句话，方案三套起（约 3 分钟）

- **页面**：方案工作台（`/workspace`，三步向导 + 右侧 AI 助手）
- **操作与话术**：
  1. 点击预置「矿山施工」示例，或只输入半句需求（如"帮我做个矿山方案，年产 200 万吨"）；
  2. 系统**阻塞生成并追问缺失参数**（预算等），下方出现**补录表单** → 填 1.5 亿提交 → **自动继续生成**（无需重述需求）；
  3. 第 ② 步比选：**3 套选型方案**（型号/数量/参数）+ 三年 TCO 明细（购置/能耗/维保/残值）与对比图；
     现场把矿卡数量从 6 改成 5，**TCO 与吨成本实时重算**；
  4. 右侧「AI 方案助手」追问"第二套方案的三年 TCO 明细"（SSE 流式回答）；
  5. 第 ③ 步定稿：章节预览 + 招标响应度检查（投标方案）+ 导出 **Word / PDF**（已装 LibreOffice）。
- **演示要点**：单份方案 3–7 天 → 30 秒内；缺参不瞎编、补录即续跑；数值可溯源、可调参可复算。

## 第三幕 · 施工调度与设备地图（约 3 分钟）

- **页面**：设备地图监控（`/map`）→ 智能对话中调度命令
- **操作与话术**：
  1. 地图默认进入**离线 Three.js 真 3D 矿区**：旋转/缩放查看地形、采场、排土场、运输道路与电子围栏；
     设备为程序化几何体（挖掘机/矿卡）按状态着色，WebSocket 每 5 秒推送；
  2. 点击矿卡 → 3D 场景绘制**立体轨迹回放**（紫色管道）；可切「离线 2.5D 自绘」与「高德真实地图」对比；
  3. 回到对话输入："空载率太高，帮我调度派车"→ 返回派单表（4 条）与空载率；
  4. 制造故障场景："矿卡 T02 故障了，立即重调度"→ **动态重调度**排除 T02，强调"建议执行，须调度员确认"（回复"确认调度方案"下发）。
- **演示要点**：3D 完全离线零外部依赖，断网可演示；车铲匹配 + 人机协同安全边界。

## 第四幕 · 智能运维：预警 → 诊断 → 工单 → 归档 全链路（约 4 分钟）

- **页面**：智能运维中心（`/maintenance`，五区）
- **操作与话术**：
  1. **设备运营**：一屏看完台账（状态/利用率/工时/油耗/健康评分/保养到期/备件预警）→ 对"保养到期"设备点"保养工单"；
  2. **预警中心**：切换模型来源——本矿设备（v1 温漂模型）或**语料仿真设备（企业级多检测器，P1 检出 10/10、平均提前量 24.3h）**；
     点任一真实故障标签验证命中对应部件（如 DEV-011 → 液压系统）；预警详情抽屉展示**五要素**；
  3. **智能诊断**：从预警一键带参 → Top3 诊断及递减置信度（78%/74%/70%）+ 维修方案/备件/工时/推荐工程师；
     再输入知识库外问题验证**拒答**（不编造、转人工）；
  4. **工单中心**：点开 `WO-FLOW-*` 工单 → 按**六状态机**逐级推进（已生成→已派工→维修中→待验收→已完成→已归档），
     填备注与实际工时 → **时间线实时留痕**；尝试回退会被拒绝；
  5. **维修归档**：查看归档工单、**MTTR**、故障分布、备件消耗与复发设备统计（案例回写知识库）。
- **演示要点**：从"预警"到"归档"一条链闭环；状态变更可审计（谁/何时/为什么）。

## 第五幕 · 智能对话：自然语言运营中枢（约 3 分钟）

- **页面**：智能对话（`/chat`）
- **操作与话术**：
  1. 用一句自然语言提问"帮我生成矿山施工方案…"→ 看 **SSE 流式逐字输出**与智能体路由标签、引用来源；
  2. 多轮追问："把上面方案里第二套的三年 TCO 报给我"→ 记忆上下文并回答；
  3. 左侧栏把该会话**归档** → 切到「已归档」组 → 再**恢复**并**重命名**（历史可管理、可检索）；
  4. 换话题："T04 会不会出问题？"→ 运维智能体预测；问"露天矿爆破单耗一般多少？"→ RAG 带句级摘要与引用（0.35~0.55 kg/m³）；
  5. 演示结束页：转人工入口。
- **演示要点**：一个入口触达五类智能体；需求槽位跨轮记忆（场景/产量/工期/预算状态条可见）。
